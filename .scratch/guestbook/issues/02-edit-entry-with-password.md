# 02: 글 비밀번호로 내 글 메시지 수정하기

**What to build:** 글쓴이가 자기 글의 [수정]을 누르면 기존 메시지가 채워진 입력칸과 비밀번호 입력칸이 그 글 아래에 열린다. 비밀번호가 맞으면 메시지가 바뀌고 "(수정됨 · 시각)"이 붙으며, 틀리면 "비밀번호가 일치하지 않습니다."가 보이고 글은 그대로다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 올바른 글 비밀번호로 메시지가 수정되고 수정 시각이 기록된다
- [ ] 이름, 작성 시각, 목록 순서는 수정 후에도 그대로다
- [ ] 틀린 비밀번호(다른 글의 비밀번호 포함)는 거부되고 메시지·수정 시각이 바뀌지 않으며 안내 문구가 보인다
- [ ] 수정 메시지도 1~500자 규칙으로 검증된다
- [ ] 없는(이미 삭제된) 글이면 "이미 삭제된 글입니다."가 보인다
- [ ] [취소]로 폼을 닫을 수 있다
- [ ] store 모듈 테스트가 위 동작을 검증하며 그린
