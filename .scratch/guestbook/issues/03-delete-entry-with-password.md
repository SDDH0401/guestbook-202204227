# 03: 글 비밀번호로 내 글 삭제하기

**What to build:** 글쓴이가 자기 글의 [삭제]를 누르면 비밀번호 입력칸이 그 글 아래에 열린다. 비밀번호가 맞으면 글이 목록에서 사라지고, 틀리면 "비밀번호가 일치하지 않습니다."가 보이고 글은 그대로 남는다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 올바른 글 비밀번호로 글이 삭제되어 목록에서 사라진다
- [ ] 틀린 비밀번호(다른 글의 비밀번호 포함)는 거부되고 글이 남으며 안내 문구가 보인다
- [ ] 없는(이미 삭제된) 글이면 "이미 삭제된 글입니다."가 보인다
- [ ] [취소]로 폼을 닫을 수 있다
- [ ] store 모듈 테스트가 위 동작을 검증하며 그린
