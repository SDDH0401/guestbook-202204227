# 01: 방명록 글 남기기 + 최신순 목록 보기

**What to build:** 방문자가 한 페이지에서 이름·메시지·글 비밀번호를 입력해 방명록 글을 남기면, 그 글이 작성 시각과 함께 목록 맨 위에 나타난다. 목록은 작성 시각 최신순이고, 글이 없으면 안내 문구가 보인다. 헤더에 개발자 이름과 학번이 보인다. 이 티켓이 스키마, DB 연결, 마이그레이션 스크립트, store 모듈과 PGlite 테스트 하네스를 함께 깐다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `entries` 스키마가 여러 번 실행해도 안전한 SQL로 존재하고 `npm run db:migrate`로 적용된다
- [ ] 비밀번호는 scrypt 해시(글마다 다른 salt)로만 저장되고 목록 결과에 해시가 포함되지 않는다
- [ ] 이름 1~20자, 메시지 1~500자, 비밀번호 4~50자(앞뒤 공백 제거 후) 규칙을 어기면 이유와 함께 거부되고 입력값이 폼에 남는다
- [ ] 목록은 작성 시각 최신순이며 이름·메시지·KST 작성 시각이 보인다
- [ ] 글이 없으면 "아직 방명록 글이 없습니다"가 보인다
- [ ] 헤더에 "개발자: 신동현 (202204227)"이 보인다
- [ ] store 모듈 테스트(PGlite)가 작성·정렬·검증·해시 미노출을 검증하며 그린
